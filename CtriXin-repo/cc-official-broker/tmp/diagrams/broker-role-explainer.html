    subgraph Client[Client 侧]
        U[你 / 多台电脑]
        MMS[client MMS\n本地入口]
        LH[Local Runner\n本地文件 / 命令 / Git]
    end

    subgraph Middle[中间层]
        B[Broker\n会话路由 / 设备鉴权 / 隔离 / 统计 / tool bridge]
    end

    subgraph Server[Server 侧]
        SM[server-side MMS\n未来可做多 OAuth / 多 runtime 调度]
        RS[Remote Runtime Service\n把请求转成远端 runtime 调用]
        OCC[official Claude Code runtime\n真实 OAuth / 真正推理与远端 session]
    end

    U --> MMS
    MMS -->|选择 profile| B
    B -->|普通 prompt / session| SM
    SM -->|选中一组 OAuth / runtime| RS
    RS --> OCC

    OCC -->|需要读文件 / 跑命令| B
    B -->|tool.call / tool.result| LH
    LH --> B
    B --> OCC

    B -. 负责 .-> R1[1. device_key 鉴权]
    B -. 负责 .-> R2[2. session truth]
    B -. 负责 .-> R3[3. workspace/device 隔离]
    B -. 负责 .-> R4[4. usage stats]

    MMS -. 不负责 .-> X1[不直接做远端 OAuth]
    LH -. 不负责 .-> X2[不做远端推理]
    OCC -. 不直接看到 .-> X3[你的本机文件系统]
